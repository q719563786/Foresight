# 远见 0.7 使用体验重构设计

## 目标

把当前的“数据展示后台”重构成普通人每天能直接使用的“个人利益行动中心”。首页先回答三件事：发生了什么、为什么与我有关、我现在要做什么；原始信息、证据和系统参数放到下一层。

## 已确认的问题

- 首页三个数字是普通 `div`，视觉上像按钮但不能点击。
- 事件摘要中保存并显示了 RSS/网页 HTML 片段，产生裸露的 `<a>`、`<font>` 和超长文本。
- 192 个事件簇与 1003 条外部信息一次性渲染，页面高度接近 2–3 万像素，出现横向滚动和明显操作负担。
- 通知只有展示，没有“已读”“全部已读”和跳转到相关事件的完整操作闭环。
- `low_sample`、`rising`、`active`、ISO 时间等内部值直接暴露给用户。
- 设置页复选框被通用输入框样式拉满，登录启动按钮缺少统一样式。
- 页面切换、刷新和保存多依赖空白等待、`alert` 或 `confirm`，缺少持续可见的加载、成功与失败反馈。
- 导航有 11 个同级入口，内部账本和外部情报混在一起，日常入口不清晰。

## 产品结构

主导航收敛为四组：

1. **行动中心**：今天需要处理的事件、待判断项、未读提醒。
2. **外部世界**：经过规则过滤的事件雷达、原始信息流、来源健康状态。
3. **我的利益**：利益对象、正式预测、模型校准与历史表现。
4. **系统设置**：知识库、监控、开机启动、可选外部 AI 和高级配置。

原有功能保留，不删除预测账本、信号、知识库或利益地图；低频功能通过二级导航或页面内部入口访问。

## 行动中心

### 顶部状态

- 显示后台是否监控、最后更新时间和来源失败数量。
- “立即更新判断”只有一个主按钮；运行时禁用并显示阶段，完成后显示本次新增、研判、提醒数量。
- “安全退出”保留在系统菜单；关闭窗口默认缩到托盘。

### 三个可点击指标

- 重要事件
- 等你判断
- 未读提醒

三个指标都使用原生 `button`，点击后更新选中态、列表标题、结果数量和筛选条件。支持键盘和明确焦点状态。

### 事件列表

- 默认每页 10 条，后端分页，禁止一次返回全部历史记录。
- 支持关键字、领域、证据等级、待判断和未读状态筛选。
- 卡片只显示清洗后的标题与摘要、中文证据说明、来源数量、相对时间和个人影响摘要。
- 整行可打开详情，同时保留明确的“查看判断”按钮。
- 空结果、加载失败、后台繁忙和来源不可用均有独立文案。

### 右侧行动队列

- 只放最紧急且可执行的 1–3 项。
- 每项显示原因、预计处理成本和下一步入口。
- 证据不足时明确写“暂不建议行动”，避免制造虚假确定性。

## 事件详情

- 顶部提供返回按钮，不依赖浏览器历史。
- 分区显示事实判断、证据等级、因果链、反对证据、不确定性、时间窗口和公开来源。
- “对你的影响”与公开事实分开，明确标记为本地私人映射。
- 反馈、确认候选预测等操作使用内联状态或右下角轻提示，不使用阻塞 `alert`。
- 外部链接只允许已有的 HTTP/HTTPS 公网地址，并在新窗口打开。

## 外部世界

- “事件雷达”展示已过滤、已聚合的信息；“原始信息流”仅用于核对来源。
- 原始信息也采用后端分页与搜索，不再一次渲染 1003 条。
- 来源状态翻译为“正常、待重试、已暂停、内容陈旧”；真实显示超时、证书、响应过大和反爬错误。
- 任何抓取失败都表述为“来源不可用/抓取失败”，不表述为“没有新闻”。

## 通知中心

- 支持只看未读、单条标为已读、全部标为已读、打开关联事件。
- 列表分页；已读状态即时更新顶部计数。
- 批量已读新增受本机会话令牌保护的 POST 接口。

## 表达与格式

- 证据：`E1` 显示“单一来源线索”，`E2` 显示“多源互证”，`E3` 显示“含官方来源的强证据”，`E4` 显示“高强度公开证据”。保留编号以方便审计。
- 趋势：`rising/stable/falling/low_sample` 显示“上升/稳定/下降/样本积累中”。
- 状态：`active/read/unread/ok/error` 显示中文。
- 时间：同日显示“今天 HH:mm”，昨日显示“昨天 HH:mm”，七日内显示“N 天前”，更早显示本地日期。
- 所有用户可见文本先去除脚本、样式和 HTML 标签，再解码实体、压缩空白并截断。

## 技术设计

### 文本清洗边界

新增 `text_cleaning.py`，使用 Python 标准库 `html.parser` 与 `html.unescape` 清洗历史数据的 API 输出；同时在新外部条目写入前清洗标题和摘要。数据库不做破坏性批量迁移，已有原始记录保留，随时可回滚。

### 分页接口

- `GET /api/cognition/clusters?limit=10&offset=0&q=&category=&evidence=&needs_judgment=` 返回 `{items,total,limit,offset}`，同时保留 `clusters` 别名以兼容旧客户端。
- `GET /api/external/radar?limit=10&offset=0&q=` 返回 `{items,total,limit,offset}`。
- `GET /api/notifications?limit=20&offset=0&status=` 返回 `{notifications,total,limit,offset}`。
- `POST /api/notifications/read-all` 返回更新数量。
- 所有 limit 限制为 1–100，offset 不小于 0；非法筛选值返回 400。

### 前端边界

- `ui_core.js` 只放可单元测试的格式化、翻译、查询参数和分页状态函数，浏览器与 Node 共用。
- `app.js` 负责 API、路由、事件绑定和各页面渲染。
- `index.html` 提供四组主导航、状态区、全局轻提示与加载容器。
- `styles.css` 改为可维护的分段 CSS，所有布局在 320px–桌面宽度内不产生页面级横向滚动。

## 安全与隐私

- 服务仍只允许绑定 `127.0.0.1`，全部 API 仍校验每次启动生成的会话令牌。
- 私人利益、地址、医疗、债务、密钥、Obsidian 原文和本地数据库不进入源码、安装包日志或 GitHub。
- 不关闭 TLS 校验，不绕过反爬，不新增远程遥测。
- GitHub 仓库继续保持 private；发布前再次检查可见性与隐私扫描。

## 兼容、迁移与回滚

- 不删除或重命名数据库表；0.6 私人数据库可直接由 0.7 打开。
- 保留旧 API 的主要字段名，新增分页元数据，避免后台服务和旧测试失效。
- 0.7 打包到新的 `YuanJianApp-v0.7` 目录，0.5 和 0.6 安装包保留。
- 若 0.7 验收失败，可直接退出并启动 0.6；不需要回滚私人数据。

## 验收标准

- 三个指标可点击、可键盘操作并真实筛选列表。
- 首页和外部信息流首屏最多渲染 10 条，翻页后保持筛选条件。
- API 与界面不再显示任何 HTML 标签片段或上述英文内部状态。
- 通知可单条/批量标已读，并同步更新未读计数。
- 运行认知、刷新来源和保存设置都有忙碌、成功、失败反馈，按钮能恢复。
- 128 项既有测试继续通过，新增行为有先失败后通过的自动化测试。
- 隐私扫描通过；PyInstaller 独立程序可启动、缩到托盘、恢复窗口和安全退出。
- 真实桌面验收覆盖四个主入口、指标筛选、搜索、翻页、通知和设置页，窗口无横向滚动。
