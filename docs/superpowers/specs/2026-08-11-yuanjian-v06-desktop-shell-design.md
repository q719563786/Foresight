# 远见 v0.6 桌面窗口与托盘设计

## 目标

把v0.5的“本机服务＋默认浏览器”改成真正独立的Windows桌面窗口。保留现有采集、聚类、研判、利益映射、预测账本、SQLite私人数据库和隐私边界，不重写预测核心。

成功标准：双击`YuanJian.exe`后只出现“远见”窗口，不出现默认浏览器、地址栏或网页标签；关闭窗口后程序缩到系统托盘并继续监控；只有明确选择“退出远见”才结束后台。

## 技术选择

- 使用pywebview承载现有HTML/CSS/JavaScript界面，Windows渲染器固定为Edge Chromium/WebView2。
- 使用pystray提供系统托盘图标和菜单。
- 继续使用仅监听`127.0.0.1`的现有HTTP API和会话令牌，不开放局域网端口。
- 不引入Electron，不重写成C#，不迁移数据库。

若当前电脑缺少可用的WebView2运行时，程序必须显示明确的中文错误和修复说明，不得静默退回默认浏览器。

## 窗口与后台生命周期

1. 正常双击：启动后台服务、调度器和托盘，然后显示一个可缩放的“远见·外部认知大脑”窗口。
2. 点击窗口右上角关闭：拦截关闭事件，隐藏窗口；采集、聚类、研判和通知继续运行。
3. 点击托盘图标或“打开远见”：恢复并聚焦同一个窗口，不创建第二个窗口。
4. 托盘菜单包含：打开远见、立即运行认知、暂停/恢复自动监控、退出远见。
5. “退出远见”和界面内“安全退出”执行同一条安全关闭链：停止调度器、关闭本机服务、删除运行发现文件、释放单实例锁、移除托盘图标并结束进程。
6. 登录自启：程序以隐藏窗口方式启动，只显示托盘图标，不打扰用户。
7. 重复双击：第二实例通过现有运行发现文件联系第一实例，让第一实例显示窗口，然后第二实例退出。

## 组件边界

新增`DesktopShell`，只负责窗口和托盘，不读取数据库、不参与预测：

- `show_window()`：显示并聚焦窗口。
- `hide_window()`：隐藏窗口。
- `run_cognition()`：调用已有本机认知入口并在完成后刷新窗口。
- `toggle_monitoring()`：调用调度器的暂停/恢复接口。
- `request_exit()`：触发唯一的安全关闭链。

pywebview和pystray通过可注入适配器隔离，使生命周期逻辑可以在无GUI的自动测试中验证。现有`Application`继续负责数据库、服务和调度器装配。

## “立即运行认知”交互修复

当前故障根因是操作执行期间及完成后没有可见反馈。v0.6要求：

1. 点击后立即禁用按钮，文字变为“正在运行认知…”，页面显示已用时间。
2. 处理中明确提示正在执行聚类、证据核验、研判和利益映射，不让用户误以为点击无效。
3. 完成后显示结果摘要：历史回填数、排队研判数、成功/延期/失败数、更新利益影响数、提醒数和总耗时。
4. 即使没有新增内容，也显示“运行完成，本次没有新增待处理信息”。
5. 网络、数据库或研判异常必须显示具体中文错误；按钮在`finally`阶段恢复可点击。
6. 连续点击只允许一个前台认知任务，后台调度与手动任务共享单飞锁，避免重复处理和状态互相覆盖。

## 外部链接

事件卡片里的原始新闻来源仍用用户默认浏览器打开，因为它们是真正的互联网网页；远见自身的界面不再进入浏览器。窗口只允许加载`127.0.0.1`的远见页面，外部导航必须交给系统浏览器。

## 数据与隐私

- 继续使用`%LOCALAPPDATA%\YuanJian`中的私人数据库、备份、运行状态和DPAPI密钥。
- 桌面化不改变数据库结构，不需要迁移私人数据。
- 窗口令牌只在本机进程和回环接口中使用，不写日志或公开源码。
- GitHub发布物继续排除私人数据库、密钥、个人规则、预测历史和运行缓存。

## 错误处理

- WebView2初始化失败：显示中文错误对话框，记录不含隐私的错误类型，然后退出；不打开浏览器冒充成功。
- 托盘初始化失败：窗口仍可使用，但关闭按钮改为明确询问“最小化到任务栏”或“退出”，并显示托盘不可用状态。
- 手动认知失败：保留上次成功结果，显示失败原因，不清空事件簇和缓存。
- 退出超时：先停止接受新任务，等待当前事务完成；超过安全时限则显示“仍在关闭”，不得直接破坏SQLite文件。

## 发布与旧版本处理

- 输出新目录`YuanJianApp-v0.6`，不覆盖v0.5，确保可以回退。
- 部署验收前只读确认所有`YuanJian.exe`进程的实际路径；仅对路径明确指向v0.3的遗留进程执行一次清理，绝不按进程名批量结束未知程序。
- GitHub仍等待用户确认仓库公开或私有后再上传脱敏源码。

## 不在本次范围

- 不改变预测算法、来源规则或私人利益模型。
- 不重写为C#/WinUI，不制作安装器或自动更新器。
- 不增加云端账户、远程访问或手机端。
- 不把外部AI设为默认开启。
